# SATHRYX — The Festival of Lights

A responsive, cinematic Diwali celebration website built with **HTML, CSS and vanilla JavaScript only**.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. For the most reliable video autoplay and browser sharing, use a local static server or deploy the folder to a static host.

## Included experiences
- Cinematic looping hero video with muted autoplay
- Responsive festive background: landscape artwork on desktop, portrait artwork on mobile
- Interactive diya counter and canvas fireworks
- Personalised greeting card preview, PNG download and native share/copy fallback
- Touch-friendly rangoli drawing with colour palette, mirror symmetry, undo, clear and PNG export
- Personal wish notes stored locally in the visitor's browser
- Ambient particles, floating lanterns, responsive navigation and reduced-motion support

## Technology
- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API, Web Share API (when supported), localStorage

No framework, backend, paid API or build step is required. The wish notes are local to each browser; they are not a shared online wall because this static-only version has no server/database.
